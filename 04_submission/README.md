# 4-қатысушы: құжаттар, презентация және тапсыру

Жауапты: аты / GitHub толтырыңыз. Телефоннан мәтін дайындап, осы репозиторийге енгізуге болады.

## Қазір істейтін жұмыс

1. Төрт адамның атын және рөлін командамен нақтылаңыз; телефон нөмірі сияқты жеке деректерді public README-ге қоспаңыз.
2. `PLAN.md` ішіне презентация мен 3 минутқа дейінгі demo видео жоспарын толтырыңыз.
3. Бастапқы жоба көзін сақтаңыз: https://github.com/MakazhanAlpamys/soup-kernel-challenge . `LICENSE` және `NOTICE` сақталады.
4. Басқа қатысушылардан тек расталған нәтижелерді жинаңыз. Қазір нәтиже мен өз кернеліміз дайын емес деп ашық белгілеңіз.

## Финалға дейін

- [ ] README: не жасадық, қалай іске қосылады, нақты уақыт/жады/loss кестесі, шектеулер, идея көздері.
- [ ] `templates/SUBMISSION.md` көшірмесін түбірге `SUBMISSION.md` атымен қойып, команданың деректері мен сілтемелерін толтыру.
- [ ] Финалдық код commit SHA-сын бекіту; Kaggle-дегі `COMMIT` мәнін сол SHA-ға қою.
- [ ] Kaggle: Save & Run All; нәтижесі бар public notebook нұсқасын сақтау.
- [ ] Сол notebook сілтемесін README мен түбірдегі `SUBMISSION.md` екеуіне де жазу.
- [ ] Құжаттарға кейін commit жасалса, тексерілген код SHA мен құжат commit-ын нақты ажырату; код өзгерсе, қайта өлшеу. SHA-ны өзінің ішіне жазу үшін шексіз commit жасау қажет емес.
- [ ] Репозиторийді public ету немесе платформа арқылы жюриге рұқсат қамтамасыз ету; бұл әрекетті капитан орындайды.
- [ ] 3 минутқа дейінгі видео және презентация сілтемелері.
- [ ] Платформада жоба материалдарын 31.10.2026 23:59 Астана уақытына дейін жіберу.
