# 2-қатысушы: кернелді зерттеу

Жауапты: аты / GitHub толтырыңыз. Бірінші кезеңде GPU қажет емес; телефоннан README оқу және жазба енгізу жеткілікті.

## Қазір істейтін жұмыс

1. Түбірдегі README және ұйымдастырушылардың тапсырмасын оқыңыз.
2. `solution/swiglu.py` қалай жұмыс істейтінін оқыңыз. Бұл дайын мысал, оны өзгертіп атау біздің жеке кернеліміз ретінде есептелмейді.
3. `NOTES.md` ішіне 2–3 ықтимал операцияны жазыңыз: не есептейді, неге уақыт немесе жад үнемдеуі мүмкін, backward керек пе, қай жерге қосылады.
4. Әр алынған идеяның түпнұсқа сілтемесін көрсетіңіз. Дайын бөгде кернел кодын өз кодымыз ретінде көшірмеңіз.
5. Бірінші Kaggle нәтижесі шыққаннан кейін командамен бір операцияны таңдаңыз. Шағын операцияның өзі ≥5% уақыт талабын орындайды деп алдын ала болжамаңыз; оны өлшеу қажет.

## Кейін

Код `solution/` ішінде жазылады және `solution.apply()` арқылы іске қосылады. Осы жеке папкада тек зерттеу жазбалары тұрады. Жюри кодтан тек `solution/` папкасын таза starter ішіне көшіреді.

Тапсырманың моделін, деректерін, batch/step санын, LoRA, optimizer және Soup параметрлерін өзгертпеңіз. `harness/`, `task/`, `tests/` өзгертілмейді. Дайын unsloth, liger-kernel, flash-attn сияқты кернел кітапханаларын пайдаланбаңыз.
