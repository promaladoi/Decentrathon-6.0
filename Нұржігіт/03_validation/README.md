# 3-қатысушы: нәтижелер мен ережелерді тексеру

Жауапты: аты / GitHub толтырыңыз. Телефоннан нәтижелерді оқып, есеп толтыруға болады. GPU командаларын 1-қатысушы Kaggle-де орындайды.

## Қазір істейтін жұмыс

1. README ішіндегі Checks кестесін оқыңыз: барлығы 10 тексеру.
2. 1-қатысушыдан `runs/result.json`, `runs/checks.json` және notebook сілтемесін алыңыз.
3. `CHECKS.md` толтырыңыз. Starter-де №3 және №4 өтпейтіні күтіледі; өзге тексерулерді output бойынша тексеріңіз.
4. Уақыт, жады және eval loss көрсеткіштерін есеппен салыстырыңыз. Ұйымдастырушылардың мысал сандарын біздің нәтиже деп жазбаңыз.
5. Бірінші іске қосу қатесін ұяшық нөмірімен, traceback-пен және қайталау қадамымен тіркеңіз.

## Кейінгі тексерулер (Kaggle, репозиторий түбірінен)

```bash
python -m pytest solution -q
SOUP_APPLY_SOLUTION=1 python -m pytest tests -q
python harness/run_task.py
python harness/check_rules.py
python harness/score.py runs/result.json
```

Бұл командаларды notebook-тің Run All өлшеуімен қатар орындамаңыз. Стандарт notebook solution тестін және өлшеу/тексеру командаларын өзі орындайды; patched Soup тестін қажет болса бөлек іске қосуға болады.

Финалда барлық 10 тексеру өтуі керек. Өз Triton кернелдері әр solution іске қосуында жұмыс істеп, жиынтықта training уақытының кемінде 5%-ын алуы керек. Eval loss базадан ең көбі 0,5%, уақыт пен жады ең көбі 10% нашар болуы мүмкін. `harness/`, `task/`, `tests/` файлдарын түзетпеңіз; өз тесттеріңізді `solution/` ішінде ұстаңыз.
