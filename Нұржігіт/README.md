## Задача и результат

Ускоряем фиксированный Soup 0.77.0 / Qwen2.5-1.5B-Instruct на одной Kaggle T4.
Сохранены NF4, LoRA r=16/alpha=32 на q_proj/v_proj, batch 4, max length 512,
256 учебных строк, 64 шага, optimizer, seed и оригинальный harness.
Результат — тот же формат LoRA-адаптера и все требуемые выходы Soup.

| Показатель | Base | v45 |
|---|---:|---:|
| Полное время команды, с | 79.56 | 45.03 |
| Пик GPU, MiB | 14345 | 4135 |
| Eval loss | 2.04963 | 2.04960 |
| Повторы каждой стороны | 2 | 2 |

Время меньше на 43.4%, память на 71.2%; speedup 1.7668x, memory ratio 3.4692x.
Оба solution запуска заняли 4135 MiB. Публичный eval loss не вырос.
Свои кернелы заняли минимум 14.6% времени обучения. Полный suite: 382 passed,
1 skipped; opt-in native metadata parity отдельно прошёл. Soup: 79 passed.

## Что изменено и чей вклад

- Мерей: исправленный private training path, LM-head с фактическим масштабом
  градиента, packed dropout, метаданные и проверки публичного Tensor API.
- Владимир: общие исходные кернелы и unpadding/MLP/NF4-основа команды.
- Нұржігіт/Codex: точное компактное хранение frozen tied embedding/head,
  освобождение временных logits до следующей GEMM, ранняя компиляция storage
  proof и интеграционные проверки. Все finite значения перед упаковкой должны
  точно восстановиться из FP16; trainable параметры не упаковываются.
- Кернелы SwiGLU из примера организаторов сохранены и не выдаются за свои.

Источники и точные коммиты: [TEAM_INTEGRATION.md](TEAM_INTEGRATION.md),
[v45 provenance](04_submission/v45_provenance.json),
[организаторский starter](https://github.com/MakazhanAlpamys/soup-kernel-challenge).
Это совместный командный вариант, не независимое авторство всего кода Нұржігітом.

## Повторить измерение

1. Скачайте [закреплённый notebook](templates/codex_v45.ipynb) и импортируйте
   в новый Kaggle Notebook через File → Import Notebook.
2. Выберите GPU T4 x2, Internet On; запустите на свободной GPU.
3. Run All: notebook установит версии зависимостей, загрузит публичный
   репозиторий на точном COMMIT, подготовит фиксированные данные и выполнит
   тесты, две пары измерений и исходные 10 проверок. Используется одна T4.
4. Сохраните оригинальный ZIP, result/checks и выход notebook. Новая копия
   notebook ещё не опубликована как финальная сохранённая Kaggle-версия.

Ссылаться нужно на измеренный source commit, а не на изменяемый HEAD ветки.
В public main проект лежит внутри этой папки; notebook использует полный
проект на закреплённом development commit.

## Ограничения и состояние сдачи

Цель **30 секунд полного запуска ещё не достигнута**. Предел 7151 MiB и
проверки качества соблюдены на публичной выборке; скрытые данные проверяет жюри.
v34 сохранён в [experiments/v34](experiments/v34): 43.91 с / 7151 MiB.
Разница времени с v45 — 1.12 с в разных сессиях, не причинный A/B-тест.
Результат v44 не собран, поэтому отдельный эффект v44→v45 не установлен.
Внешний архитектурный аудит и финальная сдача на платформе не завершены;
первое место не установлено. Готовая публичная Kaggle-версия, финальные ссылки,
видео и презентация должны быть приложены к итоговой сдаче.
