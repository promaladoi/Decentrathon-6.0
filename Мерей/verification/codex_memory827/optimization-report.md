## Реализация

- Официальный upstream BAITC-Hacks/hack-a5a4072f-wither-ai, commit fc44fd2d2bf23f624e95cef655f03fecbd87ec46: все 15 файлов harness/task/tests совпадают побайтно. Исходные run_task.py, check_rules.py и набор 79 тестов не изменены; proof сохранён отдельно от solution/.
- Замороженные NF4-веса квантуются исходным native CUDA-квантизатором, затем хранятся в pinned CPU RAM. Перед матричной операцией исходные packed bytes и точные QuantState передаются на GPU; формат NF4 и конфигурация модели сохранены.
- Общая tied embedding/LM-head матрица хранится в CPU FP16 после проверки точного round-trip каждого значения; исходный FP32 output embedding и tied Parameter identity сохранены.
- Собственный lossless offload сохранённых активаций использует pinned CPU RAM. Флаги Soup activation_offloading и gradient_checkpointing остаются исходными; ни optimizer, ни seed, ни порядок данных и dropout RNG не изменены.
- MLP сохраняет узкий FP16-вход и точно пересчитывает gate/up в backward. На обычном GEMM-пути каждая временно декодированная матрица повторно используется для её input-gradient GEMM в том же backward; межшагового dense-кеша нет.
- Только приватный CPU LM-head использует блоки по 256 токенов с полной исходной шириной vocabulary. Обычный GPU LM-head сохраняет CHUNK=512; loss, метрики и rewind рассчитываются для всех исходных токенов.

Сохранена атрибуция командных вкладов Мерея, Владимира, Нұржігіта и Анаис.
Пример SwiGLU организаторов не засчитывается как собственный kernel.
