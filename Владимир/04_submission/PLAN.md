# Тапсыру материалдарының жоспары

Күйі: жоспар, дайын презентация немесе видео емес.

1. Мәселе: Kaggle T4-де Soup training уақытын / жадын азайту.
2. Біздің операциялар: NF4 dequant, residual add + RMSNorm, тек нақты токендерді есептеу + RoPE, chunked lm_head + CE, нақты жолдардағы LoRA dropout. Толығырақ: `02_kernel_research/NOTES.md`.
3. Кернел қалай жұмыс істейді: padding токендері мүлде есептелмейді, ал lm_head толық logits-ты жадқа жазбай, бөліктермен online softmax арқылы loss пен градиентті бірден шығарады.
4. Нақты нәтиже: v2 (`d080f2b`) 93.2 → 63.5 с, 1.468x; жады 14345 → 5641 MiB, 2.543x; eval loss -0.000%; 10/10 PASS. Ағымдағы `410e36b`: 79.45 → 52.3 с, шамамен 1.52x, тексерулері әлі алынбаған.
5. Шектеулер және келесі қадам: қадамнан тыс шамамен 23 с (Python, кітапханалар, модель жүктеу) кернелге тәуелсіз, сондықтан практикалық шек шамамен 1.6–1.7x. Финалдық commit-ты бір сессиядағы A/B арқылы таңдау.
