# 1-қатысушы: іске қосу және интеграция

Жауапты: компьютер қолжетімді қатысушы. Аты / GitHub: толтырыңыз.

## Қазір істейтін жұмыс

1. Kaggle аккаунтына кіріп, New Notebook ашыңыз.
2. Settings ішінде Accelerator = GPU T4 x2 және Internet = On қойыңыз. GPU қолжетімсіз болса, аккаунттағы телефон растауын және GPU квотасын тексеріңіз.
3. Репозиторийдегі `templates/kaggle_notebook.ipynb` файлын жүктеп алыңыз. Kaggle: File → Import Notebook → осы файл.
4. Бірінші код ұяшығында мынаны тексеріңіз:

   ```python
   REPO_URL = "https://github.com/BAITC-Hacks/hack-a5a4072f-wither-ai.git"
   COMMIT = ""
   ```

5. Репозиторий private болса, Kaggle Add-ons → Secrets ішінде `GITHUB_TOKEN` қосып, осы notebook үшін қосыңыз. Токенге тек осы репозиторийді оқу құқығы жеткілікті: fine-grained token, Contents: Read-only. Ұйым рұқсаты қажет болса, GitHub көрсеткен нұсқауды орындаңыз. Токенді кодқа, чатқа, GitHub-қа немесе скриншотқа жазбаңыз.
6. Run All басыңыз. Шаблон бойынша шамамен 10 минут кетеді; алғашқы жүктеу ұзағырақ болуы мүмкін. Екінші GPU-де де қатар жұмыс іске қоспаңыз: өлшеу кезінде GPU бос болуы керек.
7. Нәтижені `BASELINE.md` ішіне жазыңыз. Kaggle Output файлдарынан `/kaggle/working/repo/runs/result.json` және `checks.json` сақтап алыңыз. Қате болса, ұяшық нөмірін және қате мәтінін жазыңыз.
8. `BASELINE.md` өзгерісін команданың осы репозиторийіне commit жасаңыз.

## Бірінші іске қосудан күтілетін нәтиже

Base Soup пен шаблондағы solution орындалып, уақыт, GPU жады және eval loss көрсетіледі. Шаблонның SwiGLU кернелі команданың өз кернелі болып есептелмейді: №3 және №4 тексерулерінің өтпеуі осы кезеңде күтіледі. Басқа қателерді бөлек зерттеңіз. Бұл әлі финалдық шешім емес.

## Кейін

Таңдалған кернелді `solution/` ішіне біріктіріп, `solution.apply()` арқылы қосасыз. Басқа қатысушылар өзгеріс енгізгеннен кейін Run All алдында commit GitHub-қа түскенін тексеріңіз. Әр Run All репозиторийді жаңадан clone жасайды.
