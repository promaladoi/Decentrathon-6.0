Числа пересчитаны из округлённых значений таблицы. Они описывают starter, а не собственную оптимизацию команды. В документе указаны PASS 1, 2, 5–10 и FAIL 3, 4; доля собственных ядер 0%. Эти статусы не перепроверены по raw JSON. Даже при снижении памяти starter не допускается как готовое решение.

Обучающий loss и его кривая отсутствуют в доступных артефактах: количественный анализ невозможен. Loss модели без адаптера в этом запуске не указан; число из README организаторов нельзя использовать как результат этой сессии. Отсутствуют данные о разбросе повторов.

Если расходятся loss или outputs, проверить forward/backward, dtype, маски, число токенов и сохранение метрик; данные и настройки задачи не менять.
