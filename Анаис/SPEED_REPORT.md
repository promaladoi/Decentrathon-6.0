# Последняя проверка ускорения — V6

**Полное время: 90.19 → 52.40 с**, один холодный парный запуск на Kaggle Tesla T4. **Само обучение: 27.02 с.** Это разные метрики: полное время включает запуск, подготовку, компиляцию и сохранение адаптера.

- **187 тестов решения passed**, включая packed attention, dropout/RNG, точность NF4, градиенты, публичный Tensor-logits API и инвалидацию нового кэша.
- **79 регрессионных тестов Soup passed**.
- **10/10 официальных правил PASS**.
- Ускорение относительно base в этой сессии: **1.7212×**.
- Пиковая память: **14345 → 7977 MiB**.
- Public held-out loss: **2.04965 → 2.0497**, изменение **+0.002%** при допуске +0.5%.
- Loss curve: solution_1: first step 0.01%, mean of all steps 0.01% (max 1% and 3%).
- Доля собственных ядер: 5.8% of the training time (lowest of 1 runs, steps 3+).

**20–30 с полного запуска не достигнуты.** В этом замере цикл обучения уже попал в этот диапазон (27.02 с), однако выдавать его за полное время нельзя. Результат 52.40 с получен одним парным запуском, не медианой двух. Устойчивость на другом seed и скрытых данных не подтверждена; запуск жюри остаётся отдельной проверкой. Доля собственных ядер близка к порогу 5%, поэтому на скрытых строках потребуется повторная проверка.

## Что изменилось

Зафиксирована актуальная командная версия `Владимир/solution` из commit `13d377043fa4cdad121973a3f6179d546918e9f4`: packed native attention внутри исходного батча, точный native RNG с обработкой реальных строк dropout, сохранение публичного Tensor-logits API, корректное AMP-масштабирование градиентов lm_head и подготовка launchers в том же процессе до первого шага. NF4 arithmetic в исходнике отдельно атрибутирована Мерей (`b7c406dea7dbdc379149910efe044dccf155d083`).

Анаис: добавлен run-local кэш декодированных замороженных NF4-весов с проверкой исходных тензоров/версий и тестами изменения весов/масштабов; отключена необязательная временная диагностика, удалены чтения `/proc`. NF4-параметры остаются исходными; дополнительные плотные копии — временные данные процесса, без дискового кэша между измерениями.

Модель Qwen2.5-1.5B-Instruct, 256 train + 256 eval строк, 64 шага, порядок батчей, LoRA/dropout, optimizer и schedule сохранены. `harness/`, `task/`, `tests/` побайтно совпадают с исходным комплектом. Все проверки качества пройдены на публичных строках. Финальная отправка на платформу хакатона не выполнялась.
