# Анаис — проверенный полный запуск на одной T4

**44.14 секунды, пик GPU 4217 МиБ, 10/10 исходных проверок PASS.**
Два повтора: 44.17 и 44.12 с. 395 тестов решения + 79 Soup прошли;
один opt-in тест пропущен. Eval loss 2.04962 против 2.04969 у base.

Это время всей команды; цикл обучения отдельно — 25.64 с.
Модель Qwen2.5-1.5B-Instruct, данные, 64 шага, NF4 и настройки LoRA сохранены.
Однослотовый кэш NF4 освобождает распакованные веса предыдущей операции;
lazy CLI откладывает импорты неиспользуемых команд. Все командные атрибуции
в исходниках сохранены.

По сравнению с проверенным V7 (44.70 с / 7040 МиБ) память ниже на 40.1%.
Ранее указанные ~4135 МиБ не подменяют фактический пик этой серии 4217 МиБ.

Цель **10–20 секунд и 200–300 МБ не достигнута**. Строгий физический минимум
времени этими замерами не доказан. CPU offload уменьшает GPU-память ценой
передач и расхода RAM.
